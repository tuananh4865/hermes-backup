# Skill Library Format

This structure defines the target shape for the skill library, emphasizing rich, class-level skills over flat lists of narrow entries.

Key Facts and Structure:
*   **Skill Definition**: The format mandates CLASS-LEVEL skills, where each skill is associated with a detailed `SKILL.md` file and a dedicated `references/` directory for session-specific details.
*   **Library Philosophy**: The library must avoid being a long, flat list composed of narrow, one-session-one-skill entries.

This concept was established through a process involving fact extraction, deduplication, grouping by subject, and final curation.
