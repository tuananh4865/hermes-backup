## Reason
Update skill library structure based on user feedback for active learning.

## Raw Concept
**Task:**
Review and update the skill library structure

**Changes:**
- Adopted CLASS-LEVEL skills with rich SKILL.md files and references/ directories.
- Defined clear signals for skill updates (style/tone correction, workflow changes, new techniques, outdated skills).
- Preference order for action: 1. Update loaded skill, 2. Update umbrella skill, 3. Add support file.

**Files:**
- Conversation History

**Flow:**
User Feedback -> Signal Identification -> Preference Order Execution (Update/Patch/Add)

## Narrative
### Structure
The library should be CLASS-LEVEL skills, not narrow one-session-one-skill entries.

### Dependencies
Requires tracking user feedback signals across sessions.

### Highlights
Focus on capturing explicit corrections and emerging patterns as first-class skill signals.
