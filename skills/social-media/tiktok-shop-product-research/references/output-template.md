# Output Template — Product Research Report

Use this template after completing Steps 1-7 of the workflow. Vietnamese, casual, anh+em register.

---

## Header
```
# 🎬 TOP VIDEO REVIEW [Tên sản phẩm]
```

## Section 1: Bảng xếp hạng
Markdown table sorted by views descending:

| # | Video | Channel | Views | Thời lượng | Ghi chú |
|---|-------|---------|-------|-----------|---------|
| 🥇 | **[Title]** | [Channel] | **[X]K views** | [mm:ss] | [1-line angle description] |
| 🥈 | ... | | | | |

## Section 2: Phân tích win patterns
Use `### 📌 Top videos đều có chung pattern:` header, then 3-4 bullets explaining what made them work (the WHY, not just what).

## Section 3: Gaps (your opportunities)
Header: `## 💡 GÓC CONTENT ĐỘC ĐÁO ĐỂ ANH LÀM (CHƯA AI CÓ)`

5 numbered bullets, each with:
- Bold hook idea
- 1-2 sentence explanation of why it's a gap
- Reference to which competitor pattern it inverts/builds on

## Section 4: Market verdict
Header: `## 📊 KẾT LUẬN & KHUYẾN NGHỊ`

Three sub-sections:
- Thị trường (search volume assessment)
- Chiến lược content (3 phases if GO)
- ⚠️ Cảnh báo (honest risks)

## Section 5: Next-step CTA
Always end with:

```
**Anh muốn em làm gì tiếp?**

A) [Option 1 - typically script writing]
B) [Option 2 - typically deeper research]
C) [Option 3 - typically competitor/price check]
D) [Option 4 - typically full combo]

Em recommend **[X] trước** — [1-line rationale]. Anh chọn đi! 🚀
```

## Notes
- Use 🥇🥈🥉 for top 3 to be Telegram-friendly
- Bold view counts (`**51K views**`) for scannability
- "Anh" addresses user directly, "em" is self-reference
- "Mấy con vợ" appears only when referencing the target TikTok audience
- Keep total response under 600 words — Telegram readability matters
