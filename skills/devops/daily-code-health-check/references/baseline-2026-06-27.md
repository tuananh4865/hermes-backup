## Why This Reference Exists

The daily health check is meant to be LOW-NOISE. When metrics are stable, the report should be short. When a metric breaks the steady-state pattern, that one delta is the entire actionable signal. Future runs should:
1. Diff against this baseline FIRST
2. Report only deltas in the body
3. Keep recommendations ≤3 items
