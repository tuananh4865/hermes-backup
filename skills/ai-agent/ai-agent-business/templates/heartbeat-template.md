# HEARTBEAT.md Template

```markdown
# Heartbeat Schedule

## Every 30 minutes (8AM - 10PM)
- Check Stripe dashboard: revenue today, this week
- Check email inbox: urgent flags, customer issues
- Check for site errors or downtime
- If revenue < $[THRESHOLD], investigate and report

## Every 2 hours
- Post to X/Twitter: value tip or engagement
- Check competitor activity
- Review ad performance (if running ads)

## Every 6 hours
- Strategic review: what's working? What not?
- Update todo list with next 5 priorities
- Check pending orders or support tickets

## Morning (8AM)
Send briefing to Telegram:
```
📊 DAILY BRIEFING — [DATE]

💰 Revenue Yesterday: $[AMOUNT]
💰 Revenue This Week: $[AMOUNT]
📦 Orders Yesterday: [COUNT]
📧 Support Tickets: [COUNT]

🎯 Today
1. [PRIORITY 1]
2. [PRIORITY 2]
3. [PRIORITY 3]

⚠️ Blockers
- [ANY ISSUES]
```

## Evening (6PM)
- Send EOD summary to Telegram
- Flag anything unresolved for next day

## Night (11PM)
- Self-improvement review:
  * What failed today?
  * What bottleneck appeared?
  * What can I automate tomorrow?
- Update memory files with learnings
```
