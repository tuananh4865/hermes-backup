## 10. What this case proves about the routing rule (and what it doesn't)

**What it proves**:
- Phase -1 routing works for lifestyle gadgets (Pocket 3 accessories) when the brand keyword scan is done first.
- ARMAF-style routing failure did NOT repeat — Phase -1 promoted to BLOCKING held.
- 3-phase cap on persuasion principles (#1+#4+#5) is stable across product categories.

**What it doesn't prove**:
- This case and ARMAF are both review-tiktok project. **No test of routing into tuananh-badminton/ has happened since v0.4.0**. Future vợt Yonex request should run Phase -1 to confirm the badminton row still fires.
- Self-claim handling (the ⚠️ flag for ULANZI #1) is heuristic. If the user starts demanding zero self-claims or zero third-party-unverified claims, that policy will need a v0.6.0 update.
