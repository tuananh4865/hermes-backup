## HOOK FORMULAS (6 Types)

### 1. Shock/Surprise
- Formula: Phản đối expected belief
- "Your videos suck" (MrBeast)
- "I found the BEST loft in NYC... but nobody wants it"

### 2. Question
- Formula: Đặt câu hỏi + promise câu trả lời
- "What if 90% of YouTube success is just knowledge?"
- "Can you actually make $10K/month on YouTube?"

### 3. Stakes/Tension
- Formula: Tạo tension + consequence rõ ràng
- "Last to leave wins $10,000"
- "I tied up FBI agent + $100K bag + knife"

### 4. Visual Curiosity
- Formula: Mô tả hình ảnh unexpected
- "I rode skateboard with 1000 people on it..."
- "Imagine giant pillow fighting arena"

### 5. Bold Statement
- Formula: Claim controversial + prove
- "This ONE change 10x'd my channel"
- "The real reason you're not growing"

### 6. Proof of Expertise
- Formula: Show credibility + hint at value
- "After 14 years on YouTube..."
- "I've helped 1000 channels grow..."

## 5-SECOND HOOK STRUCTURE

```
Second 1-2: HOOK (curiosity/stakes)
Second 3-4: CONTEXT (giải thích nhanh)
Second 5: TRANSITION (dẫn vào content)
```

**MrBeast example:**
> "I tied up an FBI agent and I have $100,000 in this bag. Here's a knife, good luck. And I just run away."
> - Zero wasted words
> - Every word adds tension

---

## 4-PART SCRIPT STRUCTURE

### Part 1: HOOK (0-30s)
- Stop scroll, create curiosity
- Match title/thumbnail

### Part 2: CONTEXT (30s-2min)
- Setup situation
- Preview payoff
- Stick on topic

### Part 3: PAYLOAD (2min-end)
- Main content (reason they clicked)
- Micro-hook every 30s
- Build tension to climax

### Part 4: PAYOFF + CTA (last 30s)
- Resolve tension
- CTA: Watch another video

## TITLE FORMULAS (25 Total)

### Categories:
1. **Curiosity Gap**: "[Common Belief] → [Contradiction]"
2. **Transformation**: "Get [X] without [Y]"
3. **Numbers**: "[Number] [Specific Outcome]"
4. **Curiosity Loop**: "I [action] and [unexpected result]"
5. **Provocation**: "[Extreme/Bold Statement]"
6. **Questions**: "[Question that implies answer]"
7. **This vs That**: "Compare [A] vs [B]"
8. **Warning**: "The [X] mistake that destroys [Y]"

### Key Rules:
- Keep under 50 characters
- A/B test titles
- Curiosity + specificity

## THUMBNAIL PRINCIPLES

1. **Expressive faces** = +20-30% CTR
2. **High contrast** = scroll stopper
3. **3-item rule**: Face + Text + Visual
4. **Curiosity sparks** = make them wonder
5. **Consistency** = signature style
6. **Update old thumbnails** = performance boost

---

## EDITING RULES

### Cut Every 3 Seconds
- When talking: A-cam → B-cam → C-cam
- Prevents boredom
- Same content = more interesting

### B-Roll Every Sentence
- Every sentence needs visual support
- Relevant > Fancy
- No plastic stock actors

### Pacing Control
- Fast early → hook viewers
- Slower for payoff
- No dull moments
