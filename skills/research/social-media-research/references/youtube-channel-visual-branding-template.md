# YouTube Channel — Visual & Branding Deep-Dive Template

**Purpose:** Template for the second-pass request after basic channel research: *"làm báo cáo chi tiết về phong cách hình ảnh, nội dung, thumbnail, title, description, mô tả kênh và hệ thống kênh"*. Focus is **identity / brand DNA**, not market analysis.

**Verified:** 2026-07-11 with @VuiVe (1.18M subs, 828 videos, edutainment/facts niche)

---

## When to use this template

Trigger phrases (after a basic channel research already delivered):
- "làm báo cáo chi tiết về phong cách hình ảnh, nội dung, thumbnail, title, description, mô tả kênh và hệ thống kênh"
- "phân tích sâu visual/branding của kênh X"
- "breakdown toàn bộ brand identity kênh Y"
- "giải mã phong cách kênh Z"

Always pair with: SKILL.md section "Visual / Branding Deep-Dive Sub-Trigger" + "YouTube Channel Deep-Dive Workflow" (2-prong parallel subagent pattern + this 3rd visual subagent).

## Working example: @VuiVe case (2026-07-11)

User follow-up: *"làm một báo cáo chi tiết về phong cách hình ảnh, nội dung, thumbnail, title, description, mô tả kênh và hệ thống kênh của anh chàng Vui Vẻ này"*

**Outcome (key findings):**
- **Visual style:** Edutainment animation, warm color palette, illustration-based
- **Title formulas:** 80%+ match "Tất cả/Những X trong Y phút" pattern
- **Description template:** 4-part cố định + rotating sponsor (CellphoneS, TGDD, Odoo, Prep Edu, ...)
- **Channel ecosystem:** Main @VuiVe + Sub "Vui Vẻ Uncut" (raw channel ID) + Fanpage vuiveofficial
- **Playlists:** 14 series mapping categories (Fact lmao, Phim, Game, Bóng đá, Môn học, ...)
- **Business contact:** partners.98smedia@gmail.com + Zalo 0349585580 (Thủy Trần) + CN email contactvuive@163.com

**Lessons for next session:**
1. Subagent C for visual/branding (3rd subagent, not retrofit on A)
2. Use `browser_navigate` + `browser_snapshot` for verbatim description capture
3. Verify rotating sponsor pattern (don't assume single-sponsor)
4. Sub-channel raw ID navigation can 404 — use YouTube search workaround
5. Embed template inline in Telegram (no separate file unless >4000 chars)
